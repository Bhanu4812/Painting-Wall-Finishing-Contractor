# Artisan Walls — Painting Contractor Website

A responsive, multipage static website for a professional painting and wall-finishing contractor.

## Run locally

Open `pages/index.html` directly, or serve the folder with any static web server. For example:

```powershell
npx serve .
```

## Pages

- Two homepage designs
- About, services, service details
- Filterable projects and project details
- Color consultation and pricing
- Contact with client-side validation and Google Maps embed
- Custom 404 and coming-soon pages

## Before production launch

Replace demonstration contact details, domain URLs, social links, pricing, and connect the quote/newsletter forms to a secure backend or form service.

## Original generated imagery

Project imagery was created with OpenAI's built-in image generation workflow and stored locally under `assets/images/`.
